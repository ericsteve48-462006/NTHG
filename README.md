### Project Description
Essential+ is a collection of intentionally useless everyday apps, built as a simple desktop/mobile-style application using basic UI elements, buttons, timers, random functions, and programmed “bugs.” Each app technically works but behaves in frustrating, unpredictable, and funny ways instead of serving its actual purpose.

### The Problem (that doesn't exist)
Properly working apps 

### The Solution (that nobody asked for)
Sassy Calculator ,clock with wrong time ,Game with insane speed , calendar with wrong day
